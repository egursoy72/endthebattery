# Claude Code — Local Preferences

## Communication style
- Be concise. No trailing summaries after completing a task.
- No emojis unless explicitly asked.
- Use markdown links for file references, not backticks.

## Code style
- Write no comments unless the WHY is non-obvious.
- No unnecessary abstractions — solve the task, nothing more.
- No error handling for scenarios that can't happen.

## Behavior
- Ask before committing, pushing, or any destructive git operation.
- Prefer editing existing files over creating new ones.
- Do not add features beyond what was asked.
